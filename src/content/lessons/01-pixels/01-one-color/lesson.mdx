A shader is a small function that the graphics card runs for every pixel of the image, all at the same time.
It receives the position of the pixel and returns its color: three numbers between 0 and 1, for red, green and blue.

Click anywhere on the image. The values shown in the code never change, because this shader ignores the position.

**Your turn:** drag the numbers in the code left or right until your color matches the target.
