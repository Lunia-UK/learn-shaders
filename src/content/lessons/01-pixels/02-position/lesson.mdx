The function receives `uv`, the position of the pixel on the image.
`uv.x` goes from 0 on the left to 1 on the right.
`uv.y` goes from 0 at the bottom to 1 at the top.

Click in a few places on the image. This time the values in the code change.
Every pixel runs the same code, but with its own position.

**Your turn:** set the three numbers so your image matches the target.
